# cs-340
What helps me when writing code that is maintainable, readable, and adaptable is making sure that each part of the code needs to perform its own function while also serving the whole machine without interfering with the other parts if something were to change with that part. Working this way allows the code to effectively solve the problem while being adaptable to potentially different inputs or data sources. The code should just as easily function with a data set that has nothing to do with what the project involved. If I ever wanted to have a personal database set up for any sort of information, it wouldn't take too much effort to adapt it for that purpose. 

When taking on a problem as a computer scientist, I like to take the given problem and making sure to break it down into a list of requirements that will address that issue. For example, if someone needs to make a vehicle of some kind, it will generally need wheels, a steering apparatus, a mechanism to turn those wheels, and some kind of energy/power input source to act on the mechanism turning the wheels. Each are different parts that address the whole. My approach on this assignment in particular differed from other work I've done in that I ended up playing around with the code a lot more than I ever have to try to see how things really work from a conceptual standpoint. This gave me a better understanding on how to implement the solution for the problem.

Computer scientists are able to take concepts and implement them into virtual solutions. It is nearly impossible to quantify the exact scope of value that this provides in a general sense to today's digital age. But for the company, specifically, it vastly simplifies record keeping for the Grazioso company by allowing them to easily provide search input into the software and get the information they need instead of needing to keep physical records on all of the data involved in this project. Often times, that data will change and it undoubtedly changes even more in other scenarios outside of this one.
